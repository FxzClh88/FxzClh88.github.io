前言

飞行页侧边栏是屏幕左侧一条竖着的功能栏，有 8 个功能按钮，点一下开关对应功能，长按弹出设置窗。8 个功能：声呐 / 3D模型 / 深度图 / 视频 / 罗盘 / 虚拟遥控 / 相机 / 遥测。

一、整体思路（一个按钮 = 三件套）

每个功能按钮通过 “功能开关套路“ 工作：

开关：App.SettingsGroup.json 定义（bool）
按钮：Sidebar.qml 的 enable 字段绑定开关（点击切换）
显示：对应功能组件的 visible 绑定开关

长按按钮（url 非空）则弹出设置窗（弹窗是独立 Window）。

二、Sidebar.qml 主体（8 按钮的”户口本”）

交互逻辑：

单击：toggleActivation(id) + 翻转开关值（setPropertyByPath）
长按：url 非空 → Qt.createComponent(url) 创建弹窗

三、7 个功能逐一明细

功能 开关配置项 按钮绑定

模型(3D) view3DStatus 配置项已加
深度图 depthMap ✅ 绑定

罗盘 compassEnable ✅ 绑定
虚拟遥控 virtualControllerEnable ✅ 绑定
相机 cameraEnable ✅ 绑定
遥测 telemetryEnable ✅ 绑定
