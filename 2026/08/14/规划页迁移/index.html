前言

规划页（Plan View）的 6 个功能按钮迁移：文件 / 起始点 / 设置航点 / 兴趣区域 / 图案 / 返航。这些按钮旧版在 Qt5 下用 ButtonStyle 实现，新版 Qt6 已弃用该机制，需要改造。

一、整体思路

6 个按钮 = 一个自定义控件（CustomPlanMenuButton）× 6 + 两个弹窗 + 交互逻辑：

二、按钮控件迁移：CustomPlanMenuButton（点击变黄的秘密）

文件：src/QmlControls/CustomPlanMenuButton.qml

Qt5 → Qt6 的核心改造（这是最关键的）：

旧版（Qt5） 新版（Qt6） 原因
import QtQuick 2.3 import QtQuick Qt6 去版本号
import Controls.Styles 1.4 删掉 ButtonStyle 已废弃
style: ButtonStyle { } 包壳 background: Rectangle { } 新版直接自定义背景
style: ButtonStyle { label: Item {} } contentItem: Item {} 同上
control.pressed _rootButton.pressed control 引用在 Qt6 无意义
