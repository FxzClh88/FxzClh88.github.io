# 06 · UI 层（三大视图 + QML 组织）

> 基于 `2.0.5\source\qgroundcontrol\src\MainWindow\` 和 `src\FlyView\`

## 一、UI 层整体结构

QGC 的 UI 是**纯 QML**，根窗口是 `MainWindow.qml`（`ApplicationWindow`）。

```
MainWindow.qml（ApplicationWindow 根窗口）
 ├── FlyView（飞行视图，默认显示）★
 ├── PlanView（规划视图，默认隐藏）
 ├── toolDrawer（工具抽屉 → 加载 AnalyzeView / 车辆配置 / 设置）
 └── footer: LogReplayStatusBar（日志回放状态栏）
```

**关键：三大视图不是并列的**

| 视图 | 加载方式 | 说明 |
|---|---|---|
| FlyView | MainWindow 直接子元素，`visible` 控制 | 飞行主界面 |
| PlanView | MainWindow 直接子元素，`visible` 控制 | 任务规划 |
| AnalyzeView | toolDrawer 的 Loader 动态加载 | 日志分析（工具抽屉） |

切换用 `showFlyView()` / `showPlanView()` / `showAnalyzeTool()`，本质是改 `visible` + 加载 toolDrawer。

## 二、QGCApplication 注入的全局单例

QML 里到处都能访问 `QGroundControl.*`，这些是 C++ 侧（QGCApplication）通过 **context property** 注入的单例：

| QML 访问 | C++ 类 | 用途 |
|---|---|---|
| `QGroundControl.multiVehicleManager` | MultiVehicleManager | 多载具管理 |
| `QGroundControl.linkManager` | LinkManager | 链路管理 |
| `QGroundControl.videoManager` | VideoManager | 视频管理 |
| `QGroundControl.settingsManager` | AppSettings | 设置 |
| `QGroundControl.corePlugin` | QGCCorePlugin | 核心插件 |
| `QGroundControl.globalPalette` | — | 全局配色 |

> 这就是新版"弱化 QGCToolbox"的体现：不再集中到一个工具箱，而是**各自注册为 QML 单例**，QML 按需访问。

## 三、QML 模块 URI 组织

MainWindow.qml 的 import 清单就是模块地图：

```qml
import QGroundControl             // 核心单例 + 全局对象
import QGroundControl.Controls    // QmlControls 模块
import QGroundControl.FactControls// FactSystem 的控件
import QGroundControl.FlyView     // 飞行视图
import QGroundControl.FlightMap   // 地图
import QGroundControl.PlanView    // 规划视图
import QGroundControl.Toolbar     // 工具栏
```

每个 `import` 对应一个 `qt_add_qml_module(URI ...)`。**旧版没有这套 URI，全靠 `.qrc` 路径** —— 这是 FlyerLink 迁移 QML 时最麻烦的适配点。

## 四、FlyView 的组成（飞行主界面拆解）

从 `src/FlyView/` 目录看，飞行视图拆得很细：

| 组成 | 文件 | 职责 |
|---|---|---|
| 主文件 | `FlyView.qml` | 组装所有子组件 |
| 视频 | `FlyViewVideo.qml` + `FlightDisplayView*.qml` | 视频显示（**4 种后端**：QtMultimedia/UVC/Video/VideoOutput） |
| 地图 | `FlyViewMap.qml` | 飞行地图 |
| 工具条 | `FlyViewToolStrip.qml` + `FlyViewToolStripActionList.qml` | 右侧动作按钮列 |
| 控件层 | `FlyViewWidgetLayer.qml` / `FlyViewCustomLayer.qml` | 自定义控件层（**FlyerLink 定制挂载点**） |
| 多机列表 | `MultiVehicleList.qml` | 多载具列表 |
| 虚拟摇杆 | `VirtualJoystick.qml` | 虚拟摇杆（触屏遥控） |
| 遥测栏 | `TelemetryValuesBar.qml` | 底部遥测值 |
| 起飞前检查 | `PreFlightCheckList.qml` + 各 checklist | 检查清单 |
| 引导动作 | `GuidedActionsController.qml` + `GuidedAction*` | 一键起飞/降落/返航 |
| 避障叠加 | `ObstacleDistanceOverlay*` | 避障距离显示 |
| 云台/相机 | `OnScreenGimbalController` / `OnScreenCameraTrackingController` | 屏幕云台/相机跟踪 |

## 五、视频后端的 4 种实现（重点）

`FlightDisplayView*.qml` 有 4 个变体，这是新版视频系统重构的直接体现：

| 文件 | 后端 |
|---|---|
| FlightDisplayViewQtMultimedia.qml | Qt Multimedia（通用） |
| FlightDisplayViewUVC.qml | UVC（USB 视频类，Android） |
| FlightDisplayViewVideo.qml | 自定义视频接收器 |
| FlightDisplayViewVideoOutput.qml | 视频输出 |

> 这和 FlyerLink 的 **12 路视频**迁移直接相关——旧版是单一 VideoReceiver 写死多路，新版改成抽象 + 多后端。这是迁移难度最高的一处（详见定制模块《01-多路视频图传》）。

## 六、UI 层数据流（读 UI 就懂全局）

```
QML 组件（FlyView/PlanView）
  ↓ 读 Fact/属性
C++ 单例（multiVehicleManager / linkManager / videoManager）
  ↓ 信号/槽
业务管理器（Vehicle / PlanManager / ParameterManager）
  ↓ MAVLink
飞控
```

**双向**：飞控数据通过 `valueChanged` 等信号自动推到 QML 刷新；用户在 QML 操作通过 Q_INVOKABLE 方法 / 信号推回 C++。

## 七、对 FlyerLink 的意义（定制挂载点）

FlyerLink 的 UI 定制主要挂在这些位置：
1. **`FlyViewWidgetLayer.qml` / `FlyViewCustomLayer.qml`** —— 自定义控件层
2. **`FlyViewToolStrip`** —— 自定义工具按钮（对应 `CustomPlanMenuButton` 等）
3. **侧边栏 Sidebar** —— FlyerLink 新增（见定制模块）
4. **`VirtualJoystick.qml`** —— 虚拟遥控的官方基座
