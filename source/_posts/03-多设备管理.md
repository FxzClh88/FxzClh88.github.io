# 03 · 多架设备管理系统

> 基于 `D:\UsefulData\QGC` 的 `FirmwarePlugin.cc`、`VehicleMapItem.qml`、`FlightMap.qml`

## 一、模块概览

FlyerLink 需要同时管理多种设备（固定翼/多旋翼/VTOL/车/船/潜水器），核心定制是：**每种设备类型在地图上显示不同的自定义图标**，一眼区分。

多机管理的框架（MultiVehicleManager + selectedVehicles）是官方就有的，FlyerLink 主要加了**自定义图标**这一层。

## 二、自定义载具图标（核心定制）

### 2.1 C++ 侧：`FirmwarePlugin::vehicleImageOpaque()`（+29 行）

在 `FirmwarePlugin.cc` 里新增了根据载具类型返回图标路径的方法：

```cpp
QString FirmwarePlugin::vehicleImageOpaque(const Vehicle* vehicle) const {
    constexpr int MAV_TYPE_GROUND_ROVER = 10;  // MAVLink 标准值
    constexpr int MAV_TYPE_SURFACE_BOAT  = 11;

    if (vehicle->fixedWing()) return "/qmlimages/fixedWing.png";
    if (vehicle->vtol())      return "/qmlimages/customVtol.png";
    if (vehicle->rover()) {
        if (vehicle->vehicleType() == MAV_TYPE_GROUND_ROVER) return "/qmlimages/customCar.png";
        if (vehicle->vehicleType() == MAV_TYPE_SURFACE_BOAT)  return "/qmlimages/customBoat.png";
    }
    if (vehicle->sub())       return "/qmlimages/sub.png";
    return "/qmlimages/vehicleArrowOpaque.svg";   // 默认
}
```

**关键点**：用车和船是通过 `vehicleType() == MAV_TYPE_*` 区分的（MAV_TYPE_GROUND_ROVER=10 是车，MAV_TYPE_SURFACE_BOAT=11 是船），而不是只靠 `rover()` 布尔。

### 2.2 QML 侧：`VehicleMapItem.qml` 的 `_getSource()`（+28 行）

地图上每个载具的图标，用 QML 函数重新实现了一遍同样的逻辑：

| 载具类型 | 图标 |
|---|---|
| fixedWing | `/res/fixedWing.png` |
| multiRotor | 官方默认（vehicleImageOpaque） |
| vtol | `/res/customVtol.png` |
| rover + 车(10) | `/res/customCar.png` |
| rover + 船(11) | `/res/customBoat.png` |
| sub | `/res/sub.png` |

### 2.3 GCS 自身 Logo 替换

`FlightMap.qml` 把 GCS 自身图标从 `QGCLogoFull.svg` 换成 `QGCLogoFull.png`（配合 FlyerLink 的 Logo 定制）。

## 三、多机管理框架（官方能力，FlyerLink 复用）

| 组件 | 职责 |
|---|---|
| `MultiVehicleManager` | 管理所有载具、activeVehicle、selectedVehicles（多选协同） |
| `MultiVehicleList.qml` | 飞行界面的多机列表面板 |
| `activeVehicle` / `selectedVehicles` | 当前活跃载具 / 多选载具 |

FlyerLink 的"多设备管理"= 官方多机框架 + 自定义图标，**没有改框架本身**。

## 四、数据流

```
飞控心跳 → MultiVehicleManager 创建 Vehicle
  → Vehicle 类型（fixedWing/vtol/rover/sub + vehicleType()）
  → VehicleMapItem._getSource() 选图标
  → 地图上显示对应图标（车/船/飞机/潜水器一眼区分）
```

## 五、技术要点

1. **两套重复逻辑**：C++ 的 `vehicleImageOpaque()` 和 QML 的 `_getSource()` 逻辑重复（可能在迁移过程中并存）。维护时注意同步，或统一到 C++ 侧。
2. **MAV_TYPE 是 MAVLink 标准值**（10=车，11=船），跨版本稳定，判断可靠。
