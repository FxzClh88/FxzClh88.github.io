# 05 · 水下专用组件（声纳/DVL + 深度图谱）

> 基于旧版 `2.0.5\source\flyerlink\src\FlightDisplay\DvlSonar.qml`、`DepthMap.qml`、`src\Settings\UdpSender.h`

## 一、模块概览

水下专用组件包含两个独立功能：

| 功能        | 文件             | 核心             |
| --------- | -------------- | -------------- |
| 声纳/DVL 控制 | `DvlSonar.qml` | UDP 直连水下载荷     |
| 深度图谱      | `DepthMap.qml` | MAVLink 字段实时绘图 |

## 二、DvlSonar.qml —— 声纳/DVL 控制

### 2.1 核心：UDP 直连载荷

DVL（多普勒计程仪）和声纳是**独立的水下载荷（树莓派）**，不走 MAVLink，而是用 **UDP 私协议**控制：

```qml
udpSender.sendUdp("enDvl",   "192.168.2.2", 55556)   // 使能 DVL
udpSender.sendUdp("disDvl",  "192.168.2.2", 55556)   // 禁用 DVL
udpSender.sendUdp("enSonar", "192.168.2.2", 55556)   // 使能声纳
udpSender.sendUdp("disSonar","192.168.2.2", 55556)   // 禁用声纳
```

- 目标：`192.168.2.2:55556`（树莓派载荷的固定地址）
- 协议：简单文本命令（enDvl/disDvl/enSonar/disSonar）

### 2.2 手动发送功能

弹窗里还有**手动 UDP 发送**：IP / port / 数据输入框 + 发送按钮，支持十六进制（`sendHexUdp`），用于调试任意自定义命令。

### 2.3 设置项

| 设置项 | 用途 |
|---|---|
| `sonarEnable` | 声纳使能状态 |
| `dvlEnable` | DVL 使能状态 |

## 三、UdpSender —— UDP 发送器（C++ 核心）

`src/Settings/UdpSender.h`，FlyerLink 新增的极简 C++ 类，暴露给 QML：

```cpp
class UdpSender : public QObject {
    Q_OBJECT
public:
    Q_INVOKABLE void sendUdp(const QString& data, const QString& host, int port);
    Q_INVOKABLE void sendHexUdp(const QString& hexData, const QString& host, int port);
};
```

- `sendUdp`：发文本（UTF-8）
- `sendHexUdp`：发十六进制原始字节（如 `"55 66 01"`）
- 注释自述用途：`for custom device control (e.g., Raspberry Pi DVL)` —— 就是给树莓派 DVL 用的

**实现原理**：内部用 `QUdpSocket` + `QHostAddress`，`writeDatagram` 发包。注册到 QML 后，QML 直接 `udpSender.sendUdp(...)` 调用。

## 四、DepthMap.qml —— 深度图谱

### 4.1 核心：复用官方 MAVLink Inspector

`DepthMap.qml` 用 **`MAVLinkInspectorController`**（官方 QGC 的 MAVLink 消息检查器）做实时绘图：

```
用户选择：数据组（message） + 数据体（field）
  → MAVLinkInspectorController.createChart()
  → 把该字段的值实时画成折线图（ChartView）
```

### 4.2 功能

| 功能 | 说明 |
|---|---|
| 数据组/数据体选择 | 下拉选 MAVLink 消息 + 字段 |
| 实时折线图 | QtCharts ChartView，时间轴 × 数值轴 |
| 播放/暂停 | 控制绘图 |
| 时间缩放 | timeScales（1x/2x/5x/10x...） |
| 数值范围 | rangeList 缩放 |

### 4.3 "深度图谱"的本质

这是一个**通用 MAVLink 字段实时绘图工具**。"深度图谱"只是应用场景之一——选择深度/声纳相关的 MAVLink 消息字段（如 `DISTANCE_SENSOR` 的距离值、或自定义水深消息）来画曲线。

## 五、数据流

```
【声纳/DVL 控制】
QML 按钮 → UdpSender.sendUdp → UDP 包 → 树莓派载荷(192.168.2.2:55556)

【深度图谱】
飞控 MAVLink 消息 → MAVLinkInspectorController → 选中的字段值 → ChartView 实时曲线
```

## 六、技术要点（迁移/维护注意）

1. **UDP 私协议**：声纳/DVL 的 `192.168.2.2:55556` 是硬编码的载荷地址，换设备要改。协议是简单文本命令，载荷端（树莓派）有对应解析。
2. **UdpSender 迁移简单**：它不依赖 Qt5 专有 API（只用 QUdpSocket），迁到 Qt6 基本无痛。
3. **DepthMap 依赖 MAVLinkInspector**：这是官方组件，迁移时跟着官方走即可。但 QtCharts 在 Qt6 里的 API 有变化（`import QtCharts` 版本）。
4. **迁移状态**：目前新版 diff 里只有 `DvlSonar.svg`、`depthMapChart.svg` 两个图标，**核心功能（DvlSonar.qml / DepthMap.qml / UdpSender）还没迁移**。
