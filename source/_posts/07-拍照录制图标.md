# 07 · 拍照录制 / 设备图标

> 基于 `D:\UsefulData\QGC` 的 `App.SettingsGroup.json`、官方相机管理器、图标资源

## 一、模块概览

拍照/录制功能和自定义设备图标，FlyerLink 基本都是**复用官方能力 + 换图标 + 加开关**，定制深度较浅。

## 二、拍照/录制

### 2.1 官方相机管理器

官方 QGC 已有完整的相机控制链：

```
Vehicle → QGCCameraManager（相机管理器）
  → 拍照（MAV_CMD_IMAGE_START_CAPTURE）
  → 录像（MAV_CMD_VIDEO_START_CAPTURE）
```

FlyerLink 复用这套机制，没有重写。

### 2.2 FlyerLink 定制

| 定制点 | 内容 |
|---|---|
| `cameraEnable` 设置项 | 新增 bool（默认 false），侧边栏相机开关 |
| `zhaoxiangji.svg` 图标 | 侧边栏"相机"图标（照相机图形） |
| 侧边栏接入 | Sidebar 的 camera 图标绑定 `cameraEnable` |

## 三、设备图标（配合多设备管理）

FlyerLink 新增了一组自定义载具图标资源：

| 图标 | 用途 |
|---|---|
| `customCar.png` | 车（地面 rover） |
| `customBoat.png` | 船（水面 boat） |
| `customVtol.png` | VTOL |
| `fixedWing.png` | 固定翼 |
| `sub.png` | 潜水器 |
| `flyertech_blue.png/.svg` | FlyerLink 品牌 Logo |
| `QGCLogoFull.png` | GCS 自身 Logo（替换 svg） |

这些图标配合《03-多设备管理》的 `vehicleImageOpaque()` / `_getSource()` 使用。

## 四、技术要点

1. **拍照/录制 = 复用官方**，FlyerLink 只加了"相机开关"这一个设置项和图标。
2. **设备图标是纯资源文件**，逻辑在《03-多设备管理》里（按 MAV_TYPE 选图标）。
