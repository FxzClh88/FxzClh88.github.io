# 键盘控制后端迁移开发日志（2026-08-20）

## 前言

旧版 FlyerLink 虚拟遥控有「键盘」模式（W/A/S/D 控制飞机移动，O/P 解锁），新版 QGC 源码里**没有这个后端**。本次任务：把键盘控制后端（`KeyboardControlManager` / `KeyboardController`）从旧版迁到新版，并接入遥控配置弹窗。

## 二、关键改造点

### 1. 架构适配：QGCTool → 单例

旧版继承 `QGCTool`（靠 QGCToolbox 管理），**新版 QGCToolbox 已移除**。参照新版 `JoystickManager` 改成单例：

```cpp
class KeyboardControlManager : public QObject
{
    Q_OBJECT
    Q_PROPERTY(bool enabled READ enabled WRITE setEnabled NOTIFY enabledChanged)
public:
    static KeyboardControlManager *instance();   // 单例
    bool eventFilter(QObject* obj, QEvent* event) override;  // 全局键盘拦截
    ...
};
```

构造函数里：`qApp->installEventFilter(this)` + connect `MultiVehicleManager::instance()->activeVehicleChanged`。

### 2. Vehicle 接口适配（核心优先策略）

| 旧版调用 | 新版情况 | 处理 |
|---|---|---|
| `sendJoystickDataThreadSafe(5 参数)` | **14 参数**（多 buttons2 + 扩展）| 末尾补 9 个 `0` |
| `joystickEnabled()` | 不存在 | 删掉该判断 |
| `supportsThrottleModeCenterZero()` | 不存在 | 油门统一 `[-1,1]→[0,1]` |
| `setGripperAction()` / `centerGimbal()` 等 | 移到 GimbalController / 改名 | **注释掉，留 TODO**（次要功能后补）|

## 三、踩坑记录（重点）

| # | 问题现象 | 原因 | 解决方案 |
|---|---|---|---|
| 1 | 编译报错 `C2660: 函数不接受 15 个参数` | `sendJoystickDataThreadSafe` 新版是 **14 参数**，我数错多补了一个 0 | 删掉末尾一个 `, 0` |
| 2 | 按键没反应，QML 的 `KEY PRESSED` 日志不出现 | QML 焦点机制不可靠：`FlyViewWidgetLayer` 的 `Keys` 收不到按键（焦点被弹窗/地图抢走），`forceActiveFocus` 也抢不过 | **放弃 QML 焦点方案，改用 C++ 全局拦截**：`qApp->installEventFilter`，程序级监听所有按键，绕过焦点 |
| 3 | `Warning: Could not attach Keys property to MainWindow... is not an Item` | 在 `ApplicationWindow`（MainWindow.qml）上挂 `Keys`——它是**窗口不是 Item**，挂不上 | 删掉 MainWindow 里那两行（QML 里 Keys 只能挂 Item）|
| 4 | 选"键盘"后重开弹窗，默认跳回"游戏手柄" | `VirtualController.qml` 里 4 个单选 `checked` 条件**全写成了 `value === 0`**，选键盘存的也是 0 | 枚举值改对：**None=0 / 游戏手柄=1 / 虚拟摇杆=2 / 键盘=3** |
| 5 | 日志反复 `enable keyboard` / `delete keyboard` 抖动 | 单选值全 0 → radio 状态不稳定，反复触发开关 | 同上修复后消失 |
| 6 | `VirtualController.qml:90/115 TypeError` | 旧代码没判空就访问 `globals.activeVehicle` / 值类型不对 | 判空 + 枚举值修复后消失 |
| 7 | 编译报 `KeyboardController.h` 缺类型 | 缺 `QVector` / `QStringList` 头文件 | 补 include |
| 8 | **按键全通但飞机不动** | 新版 MockLink 的 `_handleManualControl`（MockLink.cc:1227）**只打印日志、不模拟运动**——官方新版行为，不是代码问题 | 连真机/公司设备即可生效 |

## 四、验证结果（全链路铁证）

```
GLOBAL KEY 87                          ← W 按下，全局拦截捕获
SEND manual: pitch= 0.8 roll= 0 ...    ← 指令带 pitch=0.8 发出（按住持续发）
SEND manual: pitch= 0 ...              ← W 松开，复位
```

按键 → 拦截 → 动作映射 → `sendManualControl` → `Vehicle::sendJoystickDataThreadSafe` → MANUAL_CONTROL 发出，**全部打通**。

## 六、可复用知识

1. **QML 键盘焦点不可靠 → 用 C++ `eventFilter` 全局拦截**：`qApp->installEventFilter(this)`，在 `eventFilter` 里判 `QEvent::KeyPress/KeyRelease`，这是最底层、最稳的方案
2. **`Keys` 只能挂 Item**，不能挂 `ApplicationWindow`（窗口）
3. **新版 QGC 架构**：QGCToolbox 已移除 → 自定义管理器改**单例**（参照 JoystickManager）
4. **新版 MockLink 不模拟手动飞行**，验证操控链路要用日志证据，别等飞机动
5. **`sendJoystickDataThreadSafe` 新版是 14 参数**（roll/pitch/yaw/thrust/buttons + buttons2 + pitch/rollExtension + aux1-6）
