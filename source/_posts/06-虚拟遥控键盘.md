# 06 · 虚拟遥控 / 键盘控制

> 基于 `D:\UsefulData\QGC` 的 `App.SettingsGroup.json`、官方 `VirtualJoystick.qml`、`Vehicle::virtualTabletJoystickValue()`

## 一、模块概览

FlyerLink 的"虚拟遥控/键盘控制"= 在屏幕上（或键盘）控制载具移动，核心是**官方已有的虚拟摇杆机制**，FlyerLink 做了"默认开启 + 独立开关"的定制。

## 二、底层 API（官方已有）

### 2.1 `Vehicle::virtualTabletJoystickValue()`

```cpp
// Vehicle.h 里的 Q_INVOKABLE
Q_INVOKABLE void virtualTabletJoystickValue(double roll, double pitch, double yaw, double thrust);
```

这是**屏幕/键盘遥控的最终落点**——所有虚拟摇杆输入最终调用这个方法，把 roll/pitch/yaw/thrust 发给飞控。

### 2.2 `VirtualJoystick.qml`（官方虚拟摇杆）

官方就有的虚拟摇杆控件（触屏拖拽产生 roll/pitch/yaw/thrust 值），显示在 FlyView 上。底层就是调 `virtualTabletJoystickValue()`。

## 三、FlyerLink 的定制

### 3.1 默认开启虚拟摇杆

`App.SettingsGroup.json` 里把官方的 `virtualJoystick` 设置项默认值从 `false` 改成 `true`：

```json
"name": "virtualJoystick",
"default": true,   // ← 原来 false，FlyerLink 改成 true
```

即 FlyerLink 一启动就显示虚拟摇杆（因为触屏操作是刚需）。

### 3.2 新增独立开关 `virtualControllerEnable`

新增设置项 `virtualControllerEnable`（bool，默认 false），用于侧边栏的"虚拟手柄"图标开关。

> **注意**：`virtualJoystick`（官方）和 `virtualControllerEnable`（FlyerLink 新增）是**两个不同的开关**。前者控制官方摇杆显示，后者是侧边栏图标的状态标记。两者的关系需要在实际使用中确认是否联动。

### 3.3 侧边栏接入

`Sidebar.qml` 里的 `VirtualHandle` 图标（youxishoubing.svg，游戏手柄图标）绑定 `virtualControllerEnable`，点击切换激活。

## 四、数据流

```
用户拖拽虚拟摇杆（VirtualJoystick.qml）
  → 产生 roll/pitch/yaw/thrust
  → Vehicle::virtualTabletJoystickValue(roll, pitch, yaw, thrust)
  → MAVLink MANUAL_CONTROL / RC_CHANNELS 消息
  → 飞控执行
```

## 五、技术要点

1. **核心复用官方**：FlyerLink 没有重新实现摇杆，只是改了默认值 + 加了开关。底层 `virtualTabletJoystickValue` 是官方 API。
2. **键盘控制**：如果 FlyerLink 有键盘控制（方向键遥控），通常是监听键盘事件后同样调 `virtualTabletJoystickValue`，复用同一套底层。（旧版是否有键盘映射需在旧版源码确认）
