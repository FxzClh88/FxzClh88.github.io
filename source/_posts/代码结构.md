## 2. **.h**  
  主要作用

    管理整个应用程序的所有用户可配置设置项，包括：

    偏好设置（固件类型、机型、UI缩放等）

    文件路径（任务、参数、日志、视频等存储位置）

    地图API令牌（Mapbox、ESRI、天地图等）

    硬件功能开关（视频、声呐、DVL、罗盘等）

    虚拟摇杆配置

    音频设置

    首次运行提示管理

    各类文件扩展名定义

  ## 3.**.cc **

  AppSettings.cc 就是 AppSettings.h 的实现文件也就是把头文件里声明的那些设置功能，真正用代码实现出来。
  
## 4.json   

这个 .json 文件是 设置项的元数据（MetaData）定义文件。

打个比方：这个 .json 文件就像是 每个设置项的"说明书"：
```json
{
    "name": "audioVolume",           // 设置名字
    "shortDesc": "控制音量",          // 简短说明
    "type": "double",                // 类型：小数
    "default": 100.0,               // 默认值：100%
    "min": 0.0,                     // 最小值：0
    "max": 100.0,                   // 最大值：100
    "units": "%",                   // 单位：百分比
    "label": "音频输出音量"          // 界面显示的名字
}
```
这样程序就知道：

    界面显示时，叫"音频输出音量"

    用滑块控件，范围是 0~100

    默认值是 100

    后面显示单位 %

    保存到配置文件时存成小数


| 文件 |	作用 |
|... | ... |
|AppSettings.h	| 声明有哪些设置（"我有音量设置"） |
|AppSettings.cc	| 实现这些设置的行为（"音量保存到硬盘"） |

这个 .json 文件	| 定义每个设置的详细属性（"音量范围0~100，默认50，单位是%"）
