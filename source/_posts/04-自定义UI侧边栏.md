# 04 · 自定义 UI（侧边栏 + 自定义按钮 + 顶部动作按钮）

> 基于 `D:\UsefulData\QGC`（迁移后）的 `Sidebar.qml`、`FlyViewCustomLayer.qml`、`QmlControls/Custom*Button.qml`、`AppSettings`

## 一、模块概览

FlyerLink 的 UI 定制分三层，全都挂在官方 FlyView 框架上：

| 层 | 文件 | 作用 |
|---|---|---|
| 左侧侧边栏 | `FlyView/Sidebar.qml`（+180） | 8 个功能图标的可展开面板 |
| 顶部动作按钮 | `FlyView/FlyViewCustomLayer.qml`（+58） | 开始 / 任务规划 / 返航 三个大按钮 |
| 自定义按钮控件 | `QmlControls/Custom*Button.qml`（4 个） | 圆形图标按钮（Qt6 适配版） |

## 二、Sidebar.qml —— 侧边栏（核心定制）

### 2.1 整体结构

一个**左侧可展开/收起的面板**：
- 收起态：只露一条触发区（`triggerZoneWidth`）+ 悬浮展开箭头
- 展开态：滑出面板（`Behavior on x` 200ms 动画），带白色圆角边框

### 2.2 8 个图标（activeList 数据驱动）

| 图标 | name | id | 关联设置项 | 长按动作 |
|---|---|---|---|---|
| DvlSonar.svg | Sonar&Dvl | dSr | 无（常显） | — |
| model3d.svg | Modul3D | Mdl | 无 | 打开 Setting3DModel.qml |
| depthMapChart.svg | depthMap | dpm | 无（常显） | — |
| shipin.svg | video | vdo | 无（常显） | — |
| statistics-meter.svg | compass | cps | `compassEnable` | — |
| youxishoubing.svg | VirtualHandle | vrh | `virtualControllerEnable` | — |
| zhaoxiangji.svg | camera | cma | `cameraEnable` | — |
| telemetryIcon.svg | telemetry | tey | `telemetryEnable` | — |

> 注意：前 4 个（声纳/3D/深度图/视频）是**水下专用**功能，`enable: ""` 表示始终显示；后 4 个（罗盘/手柄/相机/遥测）绑定了布尔设置项，可开关。

### 2.3 激活机制（activatedIconIds 字符串）

核心状态是 `activatedIconIds`，一个**逗号分隔的字符串**（如 `"dSr,Mdl,cps"`）：

- `initActivated()`：启动时遍历 activeList，读设置项决定哪些图标初始激活
- `toggleActivation(id)`：点击图标时切换（字符串里加/删 id）
- **激活的图标显示成蓝色**（`brandingBlue`），未激活是普通文字色

### 2.4 交互逻辑（关键）

```qml
onClicked: {                    // 单击 = 切换激活 + 写回设置
    toggleActivation(modelData.id)
    if (modelData.enable !== "") {
        var v = getPropertyByPath(QGroundControl, modelData.enable)
        setPropertyByPath(QGroundControl, modelData.enable, !v)  // 翻转设置值
    }
}
onPressAndHold: {               // 长按 600ms = 打开设置窗口
    if (modelData.url !== "") {
        var comp = Qt.createComponent(modelData.url)   // 动态加载
        var win = comp.createObject(); win.show()       // 如 Setting3DModel.qml
    }
}
```

### 2.5 关键设计：动态路径访问器

```qml
function getPropertyByPath(root, path) { /* "settingsManager.appSettings.compassEnable.rawValue" 逐级取值 */ }
function setPropertyByPath(root, path, value) { /* 逐级写值 */ }
```

这样侧边栏不用硬编码每个设置项，而是用**字符串路径**动态读写 QGC 里的任意设置。这是 FlyerLink 侧边栏"可扩展"的关键——加新图标只需在 activeList 加一条。

## 三、顶部动作按钮（FlyViewCustomLayer.qml）

在飞行界面**顶部居中**放了三个圆形大按钮：

| 按钮 | 图标 | 动作 |
|---|---|---|
| 开始 | TakeoffLogo.svg | `guidedControllerFlyView.confirmAction(actionStartMission)` |
| 任务规划 | PlanPathLogo.svg | `mainWindow.showPlanView()` |
| 返航 | LandLogo.svg | `guidedControllerFlyView.confirmAction(actionRTL)` |

> **本质**：把官方 FlyViewToolStrip（右侧动作按钮条）里的"开始任务/返航"等动作，重新包装成顶部大按钮，更符合 FlyerLink 的触屏操作习惯。

## 四、4 个自定义按钮控件（QmlControls/）

| 控件 | 用途 |
|---|---|
| CustomMenuButton | 圆形图标+文字按钮（顶部三按钮用这个） |
| CustomMenuStateButton | 带 checked 状态切换的按钮 |
| CustomImageButton | 纯图标按钮 |
| CustomPlanMenuButton | 规划菜单子按钮（PlanView 用） |

### Qt5→Qt6 迁移要点（CustomPlanMenuButton 里的中文注释，迁移活教材）

这个文件里 FlyerLink 团队详细记录了每个迁移点，提炼如下：

| # | 旧版（Qt5） | 新版（Qt6） |
|---|---|---|
| ① | `import QtQuick 2.3` | `import QtQuick`（去版本号） |
| ② | `import QtQuick.Controls 1.2` | `import QtQuick.Controls` |
| ③ | `import QtQuick.Controls.Styles 1.4` | ❌ 删除（ButtonStyle 已废弃） |
| ④ | `import QtGraphicalEffects 1.0` | ❌ 删除 |
| ⑤ | `import Palette 1.0` | `import QGroundControl` |
| ⑥ | `import ScreenTools 1.0` | `import QGroundControl.Controls` |
| ⑦ | `style: ButtonStyle { ... }` | `background: Rectangle { ... }` |
| ⑧ | `control.pressed` | `_rootButton.pressed`（control 无引用含义） |
| ⑪ | `label: Item {}` | `contentItem: Item {}` |

## 五、新增 9 个设置项（AppSettings）

FlyerLink 在 `App.SettingsGroup.json` 新增/修改的设置项：

| 设置项 | 类型 | 默认 | 用途 |
|---|---|---|---|
| `compassEnable` | bool | false | 罗盘开关 |
| `virtualControllerEnable` | bool | false | 虚拟手柄开关 |
| `telemetryEnable` | bool | false | 遥测开关 |
| `cameraEnable` | bool | false | 相机开关 |
| `view3DStatus` | bool | false | 显示 3D 模型 |
| `model3DPath` | string | "" | 3D 模型 .mesh 路径 |
| `personalizedModel` | string | `{"x":0,"y":0,"z":0}` | 模型旋转偏移 |
| `model3DColor` | string | `#2e86ab` | 模型颜色 |
| `virtualJoystick`（改） | bool | **true**（原 false） | 虚拟摇杆默认开启 |

## 六、定制接入点总结

```
FlyView.qml
 ├── FlyViewCustomLayer（顶部：开始/任务规划/返航）
 ├── Sidebar（左侧：8 图标功能面板）
 └── ...官方组件
```

FlyerLink 的 UI 定制**全部通过官方预留的 CustomLayer / WidgetLayer 挂载点接入**，不改动官方 FlyView 主体结构。这是"加界面 + 复用官方功能"策略的典型体现。
