## 前言 

飞行页（Fly View）地图顶部的 开始 / 任务规划 / 返航 3 个蓝色圆形按钮迁移。旧版 FlyerLink 定制功能，新版需重新接入。

## 一、整体思路

```text
CustomMenuButton（圆形蓝色按钮控件）× 3
  ├── "开始"    → 触发起飞（guidedController）
  ├── "任务规划" → 跳转规划页（showPlanView）
  └── "返航"    → 触发返航（guidedController）
```
位置：地图顶部居中，最高层级显示。

## 二、控件：CustomMenuButton（蓝色圆形的秘密）

文件：src/QmlControls/CustomMenuButton.qml

圆形（第 31 行）：

```qml
radius: _rootButton.height / 2     // 圆形 = 半径取高度一半
````

蓝色背景（第 28 行）——按钮颜色由调用处传入：
```qml
background: Rectangle {
    color: backgroundColor          // 用属性，调用处传蓝色
    ...
}
```
按下反馈：透明度变化（第 32 行）：

```qml
opacity: (_rootButton.pressed || _rootButton.checked) ? 0.8 : 1
```
## 三、3 个按钮的实现

文件：src/FlyView/FlyViewCustomLayer.qml（第 55-86 行）

① "开始"按钮——确认起飞：
```qml
CustomMenuButton {
    text:            qsTr("开始")
    imageResource:   "/res/TakeoffLogo.svg"        // 起飞图标
    backgroundColor: "#cc0088FF"                   // 蓝色半透明
    onClicked: globals.guidedControllerFlyView.confirmAction(
                   globals.guidedControllerFlyView.actionStartMission)
}
```
② "任务规划"按钮——跳转规划页：

```qml
CustomMenuButton {
    text:            qsTr("任务规划")
    imageResource:   "/res/PlanPathLogo.svg"       // 航线图标
    backgroundColor: "#cc0088FF"
    onClicked: mainWindow.showPlanView()           // 切到 PlanView
}
```
③ "返航"按钮——触发返航：

```qml
CustomMenuButton {
    text:            qsTr("返航")
    imageResource:   "/res/LandLogo.svg"           // 降落图标
    backgroundColor: "#cc0088FF"
    onClicked: globals.guidedControllerFlyView.confirmAction(
                   globals.guidedControllerFlyView.actionRTL)
}
```

## 四、位置与层级（地图顶部居中）

```qml
Item {
    anchors.top:            parent.top
    anchors.topMargin:      ScreenTools.defaultFontPixelHeight * 0.5
    anchors.horizontalCenter: parent.horizontalCenter   // 水平居中
    z: QGroundControl.zOrderTopMost                     // 最高层级，不被地图盖住
    Row { spacing: ... }                                // 3 个按钮横排
}
```
