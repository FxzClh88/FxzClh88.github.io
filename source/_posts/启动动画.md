##  前言

开头动画

## 一、🔍 旧版启动动画是怎么实现的

位置：旧版 src/QGCApplication.cc 构造函数（第 202-211 行）

```cpp
QLabel *label = new QLabel();
QMovie *movie = new QMovie(":/res/resources/donghua.gif");  // 播放 GIF
label->setMovie(movie);
movie->start();
label->showFullScreen();                                     // 全屏
QTimer::singleShot(5000, label, SLOT(close()));              // 5 秒后关闭
```
动画资源：旧版/resources/donghua.gif（飞行者图标动画）

##  二、⚠️ 不能直接照搬

新版 QGC 是 QGuiApplication（纯 QML 架构
旧版用的 QLabel + QMovie 是 Qt Widgets 组件——新版没链接 Widgets，直接搬会编译失败，强行启用还会破坏架构。

正确做法：用 QML 原生的 AnimatedImage（GIF 动画原生支持）替代 QLabel+QMovie。

## 📋 三步迁移方案

**第 1 步：复制 GIF 资源**

把旧版的 donghua.gif 复制到新版：

>>>
C:\APP_bag\QGC_1\2.0.5\source\flyerlink\resources\donghua.gif
        ↓ 复制
C:\Users\Administrator\qgroundcontrol\resources\donghua.gif

第 2 步：注册资源（改 CMake）

打开 src/CMakeLists.txt，在第 25 行（qt_add_qml_module(QGroundControlModule...) 的 ) 后面）加：

```cmake
qt_add_resources(${CMAKE_PROJECT_NAME} splash_resources
    PREFIX "/res"
    BASE "${CMAKE_SOURCE_DIR}/resources"
    FILES
        "${CMAKE_SOURCE_DIR}/resources/donghua.gif"
)
```
   这样 QML 里就能用 qrc:/res/donghua.gif 访问它

## 第 3 步：MainWindow.qml 加启动动画层（核心）

打开 src/MainWindow/MainWindow.qml，在根元素 ApplicationWindow { 的最里面（第一个子元素位置）加：

```qml
    // ====== FlyerLink: 启动动画（5 秒后自动淡出）======
    Rectangle {
        id:         splashLayer
        anchors.fill: parent
        color:      "white"                       // 背景色（按 GIF 背景调）
        z:          10000                         // 最顶层，盖住主界面

        AnimatedImage {
            id:             splashAnim
            anchors.centerIn: parent
            source:         "qrc:/res/donghua.gif"   // ← 动画 GIF
            width:          Math.min(parent.width * 0.6, 600)
            height:         width * 0.6
            fillMode:       Image.PreserveAspectFit
        }

        Timer {
            interval: 5000                        // 5 秒（和旧版一致）
            running:  true
            repeat:   false
            onTriggered: {
                splashLayer.opacity = 0           // 先淡出（500ms 动画)
                splashLayer.destroy(600)             // 延迟 600ms 再销毁（> 淡出时长）
            }
        }

        Behavior on opacity { NumberAnimation { duration: 500 } }
    }
```
