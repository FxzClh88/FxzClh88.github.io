##  前言

规划页（Plan View）的 6 个功能按钮迁移：文件 / 起始点 / 设置航点 / 兴趣区域 / 图案 / 返航。这些按钮旧版在 Qt5 下用 ButtonStyle 实现，新版 Qt6 已弃用该机制，需要改造。

## 一、🔍 旧版启动动画是怎么实现的

位置：旧版 src/QGCApplication.cc 构造函数（第 202-211 行）

```cpp
QLabel *label = new QLabel();
QMovie *movie = new QMovie(":/res/resources/donghua.gif");  // 播放 GIF
label->setMovie(movie);
movie->start();
label->showFullScreen();                                     // 全屏
QTimer::singleShot(5000, label, SLOT(close()));              // 5 秒后关闭
```
动画资源：旧版/resources/donghua.gif（飞行者图标动画）

##  二、⚠️ 不能直接照搬

新版 QGC 是 QGuiApplication（纯 QML 架构
旧版用的 QLabel + QMovie 是 Qt Widgets 组件——新版没链接 Widgets，直接搬会编译失败，强行启用还会破坏架构。

正确做法：用 QML 原生的 AnimatedImage（GIF 动画原生支持）替代 QLabel+QMovie。

**文件：src/QmlControls/CustomPlanMenuButton.qml**

Qt5 → Qt6 的核心改造（这是最关键的）：
| 旧版（Qt5）	| 新版（Qt6）	| 原因 |
| --- | --- | --- |
| import QtQuick 2.3	| import QtQuick	| Qt6 去版本号 |
| import Controls.Styles 1.4	| 删掉	| ButtonStyle 已废弃 |
| style: ButtonStyle { } 包壳	| background: Rectangle { }	| 新版直接自定义背景 |
| style: ButtonStyle { label: Item {} }	| contentItem: Item {}	| 同上 |
| control.pressed	| _rootButton.pressed	| control 引用在 Qt6 无意义 |

**点击变黄的实现**（第 24、35 行）：
```qml
property color highlightColor: "#FFF291"   // 黄色高亮
// 背景色：按下或选中 → 黄色，否则 → 默认灰
color: (_rootButton.pressed || _rootButton.checked) ? highlightColor : backgroundColor
```
## 三、"文件"按钮 → syncDropPanel 弹窗

文件：src/PlanView/PlanView.qml 第 665-890 行

1. 点击弹出对话框：在文件中插入以下内容
```qml
CustomPlanMenuButton {
    text: qsTr("文件")
    onClicked: dropPanel.show(panelEdgeTopPoint, syncDropPanel, this)  // 弹窗弹出
}
```
2. 弹窗内容：syncDropPanel = 创建计划 / 存储 / 设备 三个分组选项。
3. 宽度、位置设置：弹窗用 panelEdgeTopPoint（按钮顶部边缘点）定位 + DropPanel 组件控制宽度，按钮在哪弹窗就跟在哪。
4. 汉化：所有文案用 qsTr("...") 包裹，翻译进 translations/qgc_source_zh_CN.ts。

## 五、倒三角常显（alwaysShowArrow）

文件：src/PlanView/PlanView.qml 第 729、784、848 行

新增 alwaysShowArrow: true 属性——让弹窗按钮的倒三角提示始终显示（默认是悬停才显示）：
```qml
alwaysShowArrow: true
```
