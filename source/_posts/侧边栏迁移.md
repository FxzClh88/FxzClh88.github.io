今天开始侧边栏的迁移了，同事已经把整个侧边栏从旧版FlyerLink的UI搬过来了，接下来我来搬功能


##侧边栏模块开发
1️⃣ 侧边栏（Sidebar.qml）—— 主体

>>>是屏幕**左侧一条竖着的功能栏**，有 8 个按钮，点一下开关对应功能：
         声纳 / 3D模型 / 深度图 / 视频 / 罗盘 / 虚拟遥控 / 相机 / 遥测
>>>每个按钮对应一个"开关"（AppSettings 配置项）：`sonarView`、`view3DStatus`、`depthMap`、`videoEnable` 等
>>>有的按钮长按会弹出设置窗（如声纳弹 DvlSonar.qml、3D 弹 Setting3DModel.qml）
>>>旧版里"点侧边栏罗盘按钮 → 罗盘显示/隐藏"靠 3 个环节配合：
环节	作用	旧版位置
① 开关变量	compassEnable（是开还是关）	AppSettings（h/cc/json）
② 按钮绑定	侧边栏罗盘按钮 ↔ 开关	Sidebar.qml 第 33 行 enable: "settingsManager.appSettings.compassEnable.rawValue"
③ 显示绑定	罗盘组件 visible ↔ 开关	FlyViewWidgetLayer.qml 第 282 行

新版现状（缺什么）
环节	新版现状
① 开关	❌ 新版没有 compassEnable（要新加）
② 按钮	⚠️ 你的 Sidebar.qml 第 49 行 enable: ""（空的，要填）
③ 显示	✅ 新版罗盘在 FlyViewInstrumentPanel.qml（右下角），由 FlyViewBottomRightRowLayout.qml 第 19 行控制显示

🛠️ 三、怎么搬（3 个文件）
第 1 步：给新版 AppSettings 加开关 compassEnable（3 处小改）
文件 1：src\Settings\App.SettingsGroup.json —— （210-216行）找一个配置项后面加：
json
{
    "name":             "compassEnable",
    "shortDesc":        "compass enable",
    "longDesc":         "compass enable",
    "type":             "bool",
    "default":          false},
文件 2：src\Settings\AppSettings.h —— （第 57 行后）加一行： 
cpp
DEFINE_SETTINGFACT(compassEnable)
文件 3：src\Settings\AppSettings.cc —— （第 182 行后）加一行：
cpp
DECLARE_SETTINGSFACT(AppSettings, compassEnable)

第 2 步：填上侧边栏罗盘按钮的绑定
文件：src\FlyView\Sidebar.qml 第 49 行

qml
// 现在
{ icon: "...statistics-meter.svg", name: "compass", id: "cps", enable: " ", url: "" },
// 改成
{ icon: "...statistics-meter.svg", name: "compass", id: "cps", enable: "settingsManager.appSettings.compassEnable.rawValue", url: "" },
