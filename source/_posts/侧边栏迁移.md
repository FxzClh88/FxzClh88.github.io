## 前言

飞行页侧边栏是屏幕左侧一条竖着的功能栏，有 8 个功能按钮，点一下开关对应功能，长按弹出设置窗。8 个功能：声呐 / 3D模型 / 深度图 / 视频 / 罗盘 / 虚拟遥控 / 相机 / 遥测。

## 一、整体思路（一个按钮 = 三件套）

```text
① 开关（配置项）→ ② 按钮 enable 绑定 → ③ 显示组件 visible 绑定
```
每个功能按钮通过 "**功能开关套路**" 工作：

开关：App.SettingsGroup.json 定义（bool）
按钮：Sidebar.qml 的 enable 字段绑定开关（点击切换）
显示：对应功能组件的 visible 绑定开关

长按按钮（url 非空）则弹出设置窗（弹窗是独立 Window）。

##  四、（举例：罗盘）

## 4.1 第一步 给新版的AppSetting 加开关 compassEnable（3处小改）

文件 1：src\Settings\App.SettingsGroup.json —— （210-216行）找一个配置项后面加：
```json
{
    "name":             "compassEnable",
    "shortDesc":        "compass enable",
    "longDesc":         "compass enable",
    "type":             "bool",
    "default":          false},
```
### 4.2 第 2 步：填上侧边栏罗盘按钮的绑定

文件：src\FlyView\Sidebar.qml 第 49 行
```qml
// 现在
{ icon: "...statistics-meter.svg", name: "compass", id: "cps", enable: " ", url: "" },
// 改成
{ icon: "...statistics-meter.svg", name: "compass", id: "cps", **enable: "settingsManager.appSettings.compassEnable.rawValue"**, url: "" },
```
### 4.3 第 3 步：让新版罗盘显示跟着开关走

文件：src\FlyView\FlyViewBottomRightRowLayout.qml 第 19 行
```qml
// 现在
visible: QGroundControl.corePlugin.options.flyView.showInstrumentPanel && _showSingleVehicleUI
// 改成（加一个开关条件）
visible: QGroundControl.corePlugin.options.flyView.showInstrumentPanel && _showSingleVehicleUI && QGroundControl.settingsManager.appSettings.compassEnable.rawValue
```
## 五、长按弹窗机制（Sidebar.qml 第 165-176 行）

```qml
onPressAndHold: (mouse) => {
    if (mouse.button === Qt.LeftButton && modelData.url !== "") {
        var comp = Qt.createComponent(modelData.url)   // 动态加载弹窗
        if (comp.status === Component.Ready) {
            var win = comp.createObject()
            if (win) win.show()
        }
    }
}
```
